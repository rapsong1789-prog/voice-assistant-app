# Voice Assistant App - Bolo aur Sab Kuch Karwao

Ye app sirf bolne se kaam karti hai. Is ke andar 6 Agent hain.

## Is Ke Andar Ke Agents

1. Call Agent
Bolo "Call Karo" -> Ye kisi ko bhi call mila dega. Number bolo, naam bolo, call lag jayegi.

2. Game Agent
Bolo "Game Khelo" -> Treehouse Fishing Game khul jayega aur khelna shuru kar dega.

3. Notification Agent
Bolo "Notification Check Karo" -> Ye sari notification parh kar sunayega. WhatsApp, Email, sab kuch.

4. Camera Agent
Bolo "Camera Check Karo" -> Camera khol kar samne kya hai wo batayega. Photo bhi le lega.

5. Email / WhatsApp Agent
Bolo "Email Parho" ya "WhatsApp Parho" -> Ye parh kar suna dega.
